Act 4 · C++ 核心代碼、均攤 O(n) 證明與面試保命錦囊

FRAMES 12 – 14 · CODE & INTERVIEW DEPTH
✱ C++ CORE · 10 行最佳解O(n) / O(k)
solution.cppstd::deque<int>
deque<int> dq; vector<int> res; res.reserve(nums.size() - k + 1); for (int i = 0; i < (int)nums.size(); ++i) { if (!dq.empty() && dq.front() < i - k + 1) dq.pop_front(); // 1. 頭踢過期 while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back(); // 2. 尾踢廢物 dq.push_back(i); // 3. 新人入尾 if (i >= k - 1) // 4. 滿框記隊頭 res.push_back(nums[dq.front()]); }
① 為什麼用 if？
每次只滑 1 格，最多過期 1 個
② while <= 尾踢
比新來的弱全部踢掉
③ Python 對照
popleft / pop / append
Bottom 17% 字幕保留區 每次只滑一格最多過期一個，寫 if 就夠了！
